# Customer Segmentation Analysis using Power BI

## Project Overview
This project focuses on customer segmentation using Power BI. Customers were analyzed based on demographics and spending behavior to identify different customer groups and business insights.

## Tools Used
- Power BI
- Kaggle Mall Customers Dataset

## Features
- Customer segmentation
- Scatter plot clustering
- KPI cards
- Interactive slicers
- Demographic analysis
- Income and spending analysis

## Dashboard Insights
- Premium customers show high spending behavior.
- Some high-income customers spend less, indicating marketing opportunities.
- Customer segmentation helps businesses improve targeted marketing strategies.

## Dataset
Mall Customers Dataset from Kaggle.
